1 · 文件都在哪

~/Workspace/projects/
├── 本备忘.html                 (仓库外,给未来自己看的)
└── interpop/                   ← 项目仓库
    ├── progress.json           AI 的进度:做到哪 / 下一步 / 卡没卡
    ├── AGENTS.html             AI 的行为规矩
    ├── PROJECT_MAP.html        文件地图(项目里有什么文件、在哪)
    ├── docs/                   白皮书 · 接口清单 · SOP-P1(任务卡) · D-Gov
    └── tests/tools/map_check.py    检查地图和实际代码有没有对不上

2 · 每次开工(照抄就行)

① 打开 progress.json,看 current_pr 现在是几;
② 把 progress.json 和 AGENTS.html 两个文件发给 AI,附一句话:

"读取 progress.json 和 AGENTS.html,开始执行 PR-XX。"(XX 照 progress.json 填)

③ 它要地图就发 PROJECT_MAP.html,要任务卡就发 SOP-P1 里对应那节;
④ 它干完会给:代码文件 + 新版 progress.json + 一串 git 命令” → “验证命令 + git 命令。

3 · 它停下来问话时

看 progress.json 里的 halt_reason,知道它在问什么;给个决定, 把 blocked_by_hitl 改回 false,再喂给它,它就继续。

4 · 怎么算一个 PR 干完了

它说做完了 → 我看三眼:diff 有没有乱改别的文件(地图 diff 一眼扫)、 测试有没有偷偷改松、CI 绿没绿。没问题就说:

"PR-XX 通过,更新 progress.json 进入 PR-YY。"

5 · map_check.py 怎么养

平时不动。要改就整份发给 AI + 说哪里要变,它回新版存回去。手动改也就四个位置:

EXCLUDE = {...}        不想被检查的目录,往里加名字
map_entries() 的正则   地图条目格式变了改这
current_pr() 的正则    progress.json 字段写法变了改这
rglob("*.rs")          想查别的文件后缀改这
python3 tests/tools/map_check.py    # 改完必跑,输出绿才算改对
