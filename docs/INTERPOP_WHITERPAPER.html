§0永久封禁清单（Permanent Bans）

以下 7 项设计决策经审计收敛，确认为架构反模式，永久封禁，禁止以任何形式回流。每项封禁均附裁决依据与法定替代形态，任何代码审查、架构争议以本表为终审依据：

#封禁项裁决依据法定替代形态
1C-ABI 动态库插件注册制FFI 边界 unwind 是 UB/abort（Rust 1.71+ 直接 abort）；同时引入 ABI 稳定性灾难、符号冲突、加载失败路径三重负担。扩展通道唯一合法形态：NDJSON over Unix Domain Socket ＋ Sidecar 独立进程（§2.2、§13.2）
2_NET_WM_WINDOW_TYPE_DOCK 等 X11 窗口属性残留Wayland/Mutter 语境下无效，属外部窗口系统的历史包袱。仅使用 wlr-layer-shell-v1 / xdg-shell 标准协议（§6.1）
3slider 内核 15% 防黑硬编码业务策略渗入微内核，违反数据与业务绝缘铁律。min/max/step 全部由外部声明，内核仅执行通用几何截断（§2、§17.4-3）
4线性插值公式 LerpT_target == T_old 时除零；不具备单调收敛性，存在数值震荡隐患。一律采用 Critical Damped EMA 追赶器（§11.2）
5三线程强制拓扑跨线程投递的同步开销与结果回传延迟吃掉全部收益；徒增死锁风险与内存膨胀。单 Calloop 循环 ＋ 线程下放白名单（§11.1）
6内核直采 DMA-BUF 显存流跨 GPU modifier 花屏风险；违反 YAGNI 原则。标准 wl_subsurface 合成器硬件混叠（§13.1）
7「CPU 恒为 0.00% / 内存 <20MB」营销口径物理不可验证，导致验收失真与目标漂移。空载常驻内存 ≈15~25MB 科学控制区间（§2、§17.1）

§1立项哲学：盲服务与条件归化

1.1 问题溯源

现代桌面组件长期深陷"全能化与过度设计"的泥潭：单一进程内揉捏状态订阅、网络监控与重型图形框架（GTK/Qt/Electron）。机制与策略深度耦合的架构必然导致内核臃肿、内存泄漏，任何底层阻塞都会瞬间反噬整个桌面 UI。

1.2 盲服务定位（Blind Service）

interpop 是向 Unix 哲学（做一件事并做到极致）的强势回归，架构定性为"不主动获取数据的盲服务"。微内核不订阅网络、不监控电量、不读写音频；外部进程不给数据，内核即进入绝对静默。它是剥离了一切业务真理的"纯粹图形管道"。

1.3 条件归化栅栏（Conditional Normalization）

盲服务不等于失去主权。内核设立严苛的条件归化栅栏（16 项正交原子语义、AABB 物理越界截断、Layer-Shell 协议强制映射）。外部进程必须严格遵守契约输入结构化数据：符合条件则微秒级渲染上屏；不符合条件则静默抛弃。内核绝不崩溃，绝不反噬守护进程环境。

1.4 双向解耦架构：插件（下行注入）与扩展（上行消费）

为彻底理清系统各模块边界，微内核严格划分"能力插件"与"场景扩展"两类外部角色：

  • 插件（Plugins — 下行能力注入）：作为独立 Sidecar 进程存在的算力外挂，向微内核注入纯数据扩展算力（如 cava 音频频谱分析），输出标准 NDJSON 结果流经 P1 通道注入。未安装或崩溃时内核平滑降级，绝不闪退。形态法定见 §13.2。
  • 扩展（Extensions — 上行场景消费）：存放于系统任意路径（如 ~/.config/waybar/scripts/ 或系统目录）的外部客户端（Client），利用内核提供的画布与原子能力组装业务 UI（Waybar 挂件、Dock 坞、控制中心抽屉）。内核对扩展的存放路径与实现语言零感知、零约束。

§2最高工程法典与 ABI 红线

⚖️ 最高工程宪法法定条文

"interpop 从头到尾都不是操作系统内核，不是业务逻辑处理器，也不是通用 3D 游戏引擎。它就是一个无头软件（CLI/Daemon）与外部异构程序的极速 GUI 封装器与现代视觉微内核。它的唯一使命，就是把那些冷冰冰、无界面的命令行脚本（如音量、背光、网络、声浪），或者外部现有程序（如播放器画面流、LLM 流式文本），通过声明式的物理画布（Forms）与原子（Atoms），包装成现代高刷、动效顺滑、视觉出众的桌面图形前端。"

  • 【数据与业务绝对绝缘铁律】：interpop 永远不处理业务数据，不主导业务逻辑，只负责 UI 化与重新 UI 化，业务决策权 100% 留给原软件。严禁在内核硬编码特定业务属性（如 15% 音量防黑门限），内核仅执行通用数学截断（min/max/step 由外部声明）。
  • 【绝对快照铁律与丢弃安全绑定契约】："脏表丢弃之所以安全，前提是 patch 载荷必须是幂等绝对值快照。增量 Delta 语义下严禁丢弃中间值。"此两条为绑定契约，单独引用任何一条都是残缺的（详见 §12.3）。

    §7 中 ReactiveNode::apply_patch 的载荷类型 PatchPayload,即本条"幂等绝对值快照"铁律的强类型契约载体——编译期排除增量 Delta 与动态宽类型后门(字段级定义见《接口总清单》P2-1)。

  • 【参数透传同构铁律】：研发全周期内，核心机箱内严禁留存硬编码脚手架。测试驱动必须使用与网络 IPC 接口完全同构的强类型 Rust 结构体自顶向下透传，接入真实 Socket 时核心渲染逻辑代码变更率为 0.00%。
  • 【目标导向与科学调优】：废除"CPU 恒为 0.00%、内存 <20MB"等不可验证的营销口径（§0 封禁 #7）。确立科学资源控制底线：空载常驻内存 ≈15~25MB；事件循环静默挂起时趋近零开销。坚持"先成型，后调优，退而求其次"。

2.1 绝对禁令红线与底层系统 ABI 准则

源码严禁引入任何重量级 C/C++ 业务与全量桌面 GUI 框架（GTK4/gtk-rs、Qt6/cxx-qt、Electron 等）。应用层状态机 100% 封闭在纯 Rust 内存安全域内。内核内部严禁轮询硬件驱动文件（如 /sys/class/backlight），严禁直连 PulseAudio/PipeWire，严禁实现平铺窗口调度。

底层系统 ABI 准则：直接对接系统 Wayland Wire 协议标准与按键映射解析库（libxkbcommon.so.0）。默认基于纯 Rust CPU 矢量自洽（tiny-skia + wl_shm），可选桥接系统 Vulkan 驱动（libvulkan.so.1）以启用硬件加速后备，彻底杜绝任何因驱动缺失导致的冷启动崩溃。

2.2 唯一扩展通道 · 宪法条款

法定扩展通道为 NDJSON over Unix Domain Socket。彻底废除 C-ABI 动态链接库（.so）插件——永久宪法条款（§0 封禁 #1）。理由：unwind 穿越 extern "C" 边界是 UB/abort（Rust 1.71+ 直接 abort），且引入 ABI 稳定性、符号冲突、加载失败路径三重负担。需要极高性能的原子（如音频频谱）必须以独立 Sidecar 进程存在，通过进程边界实现 100% 内存安全隔离（详见 §13.2）。

§4实效演化与可用先行

第一原则：UI 可用先行（Content & Availability First）

首要目标是确保视口地皮精准锚定、内容盒模型排布合规、支持基础交互输入。即使全局关闭所有动画，界面也必须是一个完整、可用、尺寸收敛的静态 GUI。

第二原则：动效动画补充（Progressive Enhancement）

在可用基座绝对稳固后，叠加物理弹簧插值、150ms~250ms 平滑离场过渡，及可选的高斯模糊硬件加速管线。严禁因动效阻塞基础排版。

§5宿主溯源、IPC 安全模型与四级安全自愈

5.1 PID1 溯源与进程同生共死

无特权读取 /proc/1/comm 感知宿主 Init 体系特征（systemd 会话 / openrc / 沙盒容器）。守护进程监听 SIGTERM/SIGINT，触发法定五步析构流水线：

终止外部借核子进程 (PR_SET_PDEATHSIG)
  ➔ 阻断 IPC 神经 ➔ 卸载所有 Wayland 物理表面
  ➔ 释放 SHM/显存缓冲池 ➔ 抹除 Socket 文件句柄，确保 ≤20ms 干净退出

5.2 IPC 连接鉴权与属主生命周期绑定

建立连接时调用 getsockopt(..., SO_PEERCRED, ...) 强校验对端 UID，非属主进程直接断开。视口 target 与创建该视口的客户端连接建立强引用绑定：

  • 任何来自其他存活连接的 patch、dismiss 或重名 spawn，微内核坚决拒绝执行并回抛 {"event":"error","reason":"target_owned"}。
  • 仅当原属主连接已关闭且未残留未解租约时，方允许新连接重新接管绑定（Rebind）。
  • 全局模态独占视口（spotlight）全会话互斥，单一激活，阻断钓鱼抢焦。

租约绑定连接生命周期铁律：交互租约（§8.2）的存活期强制绑定其所属客户端连接。连接 EOF 时，微内核立即强制释放该连接名下全部租约，绝不等待"松手"事件——松手事件在客户端死亡后永远不会到来。此项防孤儿租约锁死 Rebind，比孤儿视口更难排查的静默死锁。

force 逃生门：spawn 支持 "force": true，允许同 UID 客户端强制接管已被占用的 target。安全性由 socket 层 SO_PEERCRED 的 UID 相等性保证；代价（从活着的慢客户端手里抢走视口）由 heartbeat_ms 超时清退兜底。专治"客户端被 SIGSTOP 挂起、socket 未关、EOF 不触发"的开发调试高频场景。

多会话天然免疫声明：不同 Wayland 会话各持独立 $XDG_RUNTIME_DIR，socket 天然隔离；同会话双开由 PING/PONG 互斥（§14.1）。Rebind 语义只需覆盖"同 UID 多客户端"一种战场。

5.3 运行时目录四级降级阶梯（Fallback Cascade）

  1. $XDG_RUNTIME_DIR（标准规范，权限 0700）
  2. /run/user/<UID>（系统 elogind/seatd 探测，严格验证属主与权限）
  3. $XDG_CACHE_HOME/interpop/run（用户家目录缓存隔离）
  4. /tmp/interpop-run-<UID>-<SecureHash>/（O_EXCL | O_CREAT 加固沙盒；SecureHash = BLAKE3(UID || boot_id || uuid)，熵源不可预测，阻断符号链接劫持）

6.3 双阶段离场生命周期状态机

画布作为空间宿主容器，全权掌管自身的确定性离场状态机：

                 │(配置失败)          │(触发离场)
                 ▼                  ▼
[ Destroyed ] ◀──(释放显存)── [ Reclaimed ] ◀──(动效约束)── [ Dismissing(注销输入) ]

图 6-1 · 画布生命周期状态机

  • 阶段 A · 离场请求与过渡态（Dismissing / AnimatingOut）：收到销毁信号后，画布暂不解绑底层 Surface，而是注销 input_region（阻断新的点击误触），并由渲染管线播放 150ms~250ms 平滑离场补间动效。
  • 阶段 B · 物理注销态（Destroyed / Reclaimed）：动效帧播完毕，解绑 wl_surface，向合成器安全归还独占地皮与显存句柄。

6.4 四大正交销毁策略（Dismiss Policies）

销毁策略触发机制与输入行为误伤防御保障规则
manual（缺省）仅显式下发 dismiss 或内部冒泡意图响应时销毁。绝对免疫外部焦点切换、通知弹出、桌面切换干扰；免疫全局 Escape 误杀。

单文件物理隔离：每一个原子必须独立编写于独立源码文件（interpop-atoms/src/<atom>.rs），通过统一 Trait 注册，严禁跨原子混写。公共逻辑（AABB 碰撞、颜色解析、触控容差）抽离为无状态纯函数，统一归档至公共工具模块。禁止在画布层使用巨型 match 硬编码适配具体原子类型，上层容器统一以 Box<dyn AtomNode> 多态分发。

§8正交原子矩阵与交互租约

内核不直接提供业务级组件，而是提供 16 项核心正交基元 ＋ 1 项 Feature 门控可选原子（tray）。

8.1 分级排版策略契约

  1. 几何不变型原子（slider, progress, switch）：数值变更触发零 Relayout 局部重绘，直接绕过盒模型解算。
  2. 自适应型原子（text, input, list 等）：尺寸变更触发子树 Taffy 解算，单次重排耗时强制约束在 ≤15μs 性能预算内。

8.2 交互租约锁（Interactive Lease Lock）

网络通信天然存在竞态延迟。当用户拖拽 slider 调节音量时，原子即刻向内核申请锁定 lease_id。拖拽期间，微内核硬性拦截外部轮询下发的"过期旧数据快照"，杜绝滑块疯狂抽搐。松手后释放租约锁，反向回写 intent。若外部业务执行失败，滑块顺从平滑回弹至真实状态。租约存活期强制绑定客户端连接（见 §5.2）。

§10多模态输入与分级仲裁

  • 触控容差注入：输入管道强制为触控事件注入 8 × scale_factor 物理像素的包围盒容差，确保微小滑块在触屏上 100% 命中。
  • SpatialPointer 归一化：wl_pointer 与 wl_touch 统一折叠为标准空间指针几何流，坐标域统合于逻辑像素。
  • 分级 Escape 仲裁契约（双向防线）：
    • 被动免疫防御：处于活跃编辑态的 input 原子接收 Escape，仅清空输入法与焦点，严禁穿透离场；对 dismiss_policy: manual 的持久化视口与 form: window 标准视口，Escape 严禁直接销毁画布，仅作为常规事件派发或抛出业务 intent。
    • 主动清退路由：当 spotlight 模态超视口，或策略为 click_outside/timeout/on_blur 的瞬态视口接收到未被内部原子捕获的 Escape 时，内核立即自决触发 dismiss 离场指令。
    • 策略定义回指：manual / click_outside / timeout / on_blur 四销毁策略的完整定义、触发机制与误伤防御规则，唯一权威定义见 §6.4。
  • 键盘事件全通路：通过 xkbcommon 实时维护全局按键映射与修饰键掩码；Return/Enter 自动包装为原子 intent 回写；未声明键盘焦点的视口（panel, overlay）键盘事件 100% 由合成器直接穿透分发。

§11单循环内核与免驱呈现管线

11.1 Calloop 统合与 0Hz 休眠

彻底斩断多线程死锁风险，由单一 calloop 主线程统合 UDS 监听、Wayland 分发与 POSIX 信号。当视口静止且无动效时，主动切断 VBlank 帧回调，守护进程瞬间进入 0Hz 深度休眠，杜绝无意义的轮询空转。

线程下放白名单（Hard Allowlist · 宪法条款）：仅以下三类高耗时任务允许离开主事件循环，投递至后台 worker（rayon/Tokio 池），完成后经无锁 SPSC 队列将纯数据结果送回主环：

  1. fontdb 字体全盘扫描（冷启动）；
  2. 图片解码（image crate 的 PNG/JPEG 解码）；
  3. 字形缓存 miss 时的 cosmic-text 光栅化。

Taffy 布局计算严禁出环：全树 Relayout ≤50μs，跨线程投递的同步开销与结果回传延迟会吃掉全部收益，且布局结果直接喂渲染 pass。此白名单为宪法条款，任何扩充必须附 Criterion 基准数据。

11.2 免驱自洽基座与物理坐标系上屏

渲染模式底层驱动与光栅化内存与开销特征工业应用场景与定位
默认基准模式（SHM Pure CPU）tiny-skia 纯 Rust 矢量光栅化 + wl_shm 共享内存双缓冲池。冷启动毫秒级，无 GPU 上下文占用。工业级保底：零显卡驱动门槛，在精简发行版、微型虚拟机、老旧核显上 100% 开箱即用。
加速后备模式（Hardware GPU）wgpu 管线直连系统 Vulkan 驱动（libvulkan.so.1），执行 WGSL 着色器与模糊合成。全高刷满帧渲染，显存按需动态申请，动效更丰富。宿主具备硬件驱动且需要参数化着色器特效时自动激活；驱动缺失时自动回落 CPU 管线并回抛 warning，绝不崩溃。

渲染提交采用 wl_surface.damage_buffer 精确局部增量刷新。提交参数强制执行物理像素换算（逻辑坐标 × scale_factor），从底层根除 Wayland 分数缩放下的局部重绘残影与边缘撕裂。

临界阻尼硬件追赶器（Critical Damped EMA）：高频时序数据按物理帧时钟驱动指数平滑追踪：

Value_render = Value_old + (Value_target - Value_old) × (1.0 - exp(-λ × Δt))

数学上天然单调收敛，因子严格夹取于 [0.0, 1.0)，杜绝数值震荡与除零隐患（此为对 §0 封禁 #4 线性插值除零缺陷的永久封禁）。外部显式声明 snap: true 则无延迟直达目标值。

§12IPC 大动脉与背压治理

12.1 流式分帧与断路器

依赖 BytesMut 累加器进行流式无锁分帧，配置 64KB 单行断路器防内存爆破。单行 JSON 反序列化耗时压制在 ≤5μs 极速级别。

12.2 P0/P1 双通道背压仲裁

  • P0 生命周期专用微通道（rtrb，深度 64 slots 锁死）：专供 spawn / dismiss / restyle。绝对阻塞保底——队列满时 IPC 侧挂起并以微秒级间隔重试直至入队，严禁丢弃任何生命周期事件。
  • P1 高频差分单槽脏表（AtomPatchMap，容量锁死 4096 条目，零动态扩容）：patch 差分绕过通道队列，直接写入原子分键单槽脏表。Latest-Wins：新状态原位覆盖旧状态，天然背压吸收超频拥塞。溢出时丢弃并告警（见 12.4）。
  • 告警走 P0，数据走 P1：P1 饱和时 backpressure_warning 依然经 P0 通道可达，保证可观测性永不失效。

12.3 绝对快照铁律与丢弃安全绑定契约（宪法条款）

"脏表丢弃之所以安全，前提是 patch 载荷必须是幂等绝对值快照。增量 Delta 语义下严禁丢弃中间值。"

此两条为绑定契约，单独引用任何一条都是残缺的。绝对值语义下丢弃中间值只是延迟收敛，不污染终态；Delta 语义下丢弃会永久丢失状态。patch.timestamp 必须为 CLOCK_MONOTONIC 微秒整数。

12.4 背压告警载荷富化 Schema

{"event":"backpressure_warning",
 "dropped_atom":"<atom_id>",
 "last_applied":{...},
 "tombstone_us":<micros>}

外部排查 UI 假象（"我发的 90% 哪儿去了"）可直接对账"内核当前实际渲染值"。tombstone_us 为该原子的墓碑时间戳，早于墓碑的迟到 patch 在校验前即被静默丢弃，封死状态倒流空洞。

12.5 两阶段确定性冲撞仲裁 · 心跳与竞态作废

*状态机拓扑（[Unmapped]→[Configuring]→[Active]→[Dismissing]→[Reclaimed]→[Destroyed]）唯一定义于 §6.3；本节仅定义其上的冲撞仲裁与竞态作废语义。*

外部脚本崩溃重启并重复下发同名 spawn 时，属主判定通过后降维为原位 Diff 重载，复用 Wayland Surface，严禁双重堆叠：

  • 阶段一（仍在 Dismissing 动效态）：强制中断离场动效，原地复活，重置动画时钟恢复 Active，直接执行内容 Diff。
  • 阶段二（已进入 Reclaimed，Surface 销毁不可逆）：新 spawn 入瞬态重载队列，待彻底 Destroyed 并释放显存后，原子化重新触发干净构建。

心跳与 EOF 竞态作废（Disarming）：spawn 可声明 "heartbeat_ms": 5000。心跳超时或连接 EOF 触发 dismiss 离场。150ms 离场动画期内，若外部脚本极速重启并下发同名 spawn（Rebind 接管），内核原子化作废旧销毁任务，视口停止离场原地逆转恢复。彻底消灭外挂重启带来的"闪退再闪出"刺眼感。

12.6 Taffy Panic 三级熔断

  1. 布局计算 Panic 时，立即物理丢弃整树，50μs 内重新分配，严禁在原损坏 slab 内死循环；
  2. 故障 atom_id 强制标记 display: none 并重排；
  3. 连续三次重排失败，视口绝对冻结于上一好帧，主循环永不崩溃。

§13外部进程借核与生态延伸

13.1 标准挂载（wl_subsurface）

外部异构进程（如 mpv 播放器）作为独立 Wayland 客户端启动，通过 wl_subsurface 协议原生挂载入 surface 原子容器。底层合成器执行硬件级图层混叠，内核零开销，免疫跨 GPU modifier 花屏风险（此即 §0 封禁 #6 的法定替代路径）。

13.2 Sidecar 进程模式（宪法推荐路径）

需要极高性能计算的原子（如音频频谱）必须以独立子进程存在，输出标准 NDJSON 结果流经 P1 通道注入。第一版严禁实现 SHM 环形缓冲（YAGNI：60Hz 场景 NDJSON + latest-wins 完全够用，>240Hz 需求出现时再立项）。C-ABI 动态库插件为 §0 封禁 #1，永久禁止。

13.3 防孤儿强监管

所有挂载/借核进程必须设置 PR_SET_PDEATHSIG 绑定生命周期。外部进程崩溃时，微内核在 1 个 VBlank 周期内彻底注销无效的纹理节点，回收占位符。

13.4 显存/FD 引用计数审计

共享句柄强制纳入内核引用计数字典，退出时断言 gpu-leak-audit.log: ACTIVE_LEAKS: 0。

§17生产验收与 CI 棘轮门禁

彻底消灭主观"优化文学"，将验收标准转写为冷酷的机器断言，指标只许降，不许升。

17.1 机器断言常规指标

  • 内存占用监控：空载 VmRSS 落在 ≈15~25MB 科学控制区间。
  • 热路径 Criterion 断言：NDJSON 纯反序列化 ≤5μs；首帧光栅排版并上屏提交 ≤1.5ms；Taffy 单原子子树重排 ≤15μs、全树 ≤50μs。
  • Golden 图像跨管线容差：同路径软渲染结果必须达成 BLAKE3 哈希完全一致；跨硬件 GPU 渲染采用 ΔE<2 动态视觉容差判定。
  • 黄金图像锁输入域（门禁自杀防线）：BLAKE3 一致性是三元函数 hash(输入, 字体集, 光栅化器版本)。CI 必须满足：① 测试集打包内置固定字形资产，严禁运行时动态调用宿主 fontdb 全盘扫描；② 锁死 tiny-skia 依赖版本。否则宿主字体库升级或 crate 小版本 bump 会导致 golden hash 全线假红——假阳性红一次，团队就会把门禁降级成 warning，棘轮从此报废。
  • 文档同轨修订门禁：Docs-only PR 被自动化拦截，强制架构文档变更必须与代码实现同 PR 绑定提交，断绝"文书空转"。

17.2 双通道 Soak 浸泡门禁（防慢性泄漏主力）

通道场景断言
A · 空载浸泡守护进程启动后静置 60sVmRSS 首尾漂移 ≤ 512KB（专杀启动期泄漏）
B · 灌注浸泡以 60Hz 持续灌入 patch 高频更新 60sVmRSS 首尾漂移 ≤ 512KB（专杀字形缓存、图元缓冲等 patch 路径慢性泄漏）

空载浸泡抓不住 patch 路径泄漏——后者才是真实生产中的泄漏大户，必须双通道并设。

17.3 CI Gatekeeper 完整脚本

#!/usr/bin/env bash
set -euo pipefail
cd "$(git rev-parse --show-toplevel)"

# 1. scaffold 目录必须彻底清空（安全排除 .gitkeep）
find interpop-scaffold/src/ -type f ! -name '.gitkeep' | grep -q . && {
    echo "CRITICAL ERROR: interpop-scaffold contains dirty code!"; exit 1; }

# 2. 生产 crate 严禁偷渡 scaffold 依赖
grep -rn "interpop-scaffold" interpop-core/ interpop-render/ interpop-atoms/ \
    --include="Cargo.toml" && {
    echo "CRITICAL ERROR: Illegal scaffold dependency!"; exit 1; }

# 3. 全 Workspace 静态编译断言
cargo check --workspace --all-targets

# 4. 双通道浸泡 + RSS 门禁（通道 A：空载）
export XDG_RUNTIME_DIR=$(mktemp -d /tmp/interpop-ci-XXXXXX); chmod 0700 "$XDG_RUNTIME_DIR"
interpopd --test-headless-smoke & PID=$!; sleep 2
kill -0 "$PID" 2>/dev/null || { echo "Daemon failed to spawn!"; exit 1; }

RSS_START=$(grep VmRSS /proc/$PID/status | awk '{print $2}')
sleep 60
kill -0 "$PID" 2>/dev/null || { echo "Daemon died during soak!"; exit 1; }
RSS_END=$(grep VmRSS /proc/$PID/status | awk '{print $2}')

# (a) 空载基线 ≤ 25MB
[ "$RSS_END" -gt 25600 ] && { echo "RSS exceeded 25MB!"; exit 1; }
# (b) 空载浸泡漂移 ≤ 512KB
DIFF=$(( RSS_END > RSS_START ? RSS_END - RSS_START : RSS_START - RSS_END ))
[ "$DIFF" -gt 512 ] && { echo "Idle soak drift exceeded 512KB!"; exit 1; }

# (c) GPU/句柄洁癖审计
grep -q "ACTIVE_LEAKS: 0" "$XDG_RUNTIME_DIR/interpop/gpu-leak-audit.log" || {
    echo "Leak audit failed!"; exit 1; }

rm -rf "$XDG_RUNTIME_DIR"
echo "ALL CI ASSERTIONS PASSED."

（通道 B：60Hz patch 灌注由独立测试作业执行，断言同 (b)。）

17.4 五大黑盒生产标杆验收

  1. Waybar 音量岛：宿主吸附弹出（anchor_rect 契约入口生效，§6.1/§14.1），Clamp & Flip 生效，滑块防抽搐并对齐外部脚本权威；EOF 强制释放租约后新进程可无缝 Rebind。
  2. 快捷控制抽屉：贴边全高划出，关机磁贴双语对齐，触发事件回写至 UDS 管道。
